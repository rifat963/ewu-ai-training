01 · Ethics first

Do it ethically, the EWU way

AI makes analysis fast. It does not make it ethical. These checks come before the first upload and stay with you until the disclosure statement.

East West University Research Ethical Committee (EWUREC)

"All research work at EWU should adhere to the highest ethical standards; any research work carried out at EWU which has significant ethical implications will have to be submitted for independent ethical review."

EWU has a Policy and Procedure for Research Ethics Approval and a Plagiarism Policy. This page summarises good practice; the official policy documents and the committee decide. Source: EWUREC page.

Do

  • Use public, anonymised, licensed data for practice
  • Cite the dataset and licence
  • Ask the AI to show and run its code
  • Recompute every number you report
  • Report effect sizes and limitations
  • Disclose tool, version and what it did
  • Seek EWUREC review for new human-participant data

Don't

  • Upload identifiable participant data
  • Try to re-identify anyone
  • Publish tables with cells under 10
  • Accept numbers you cannot reproduce
  • Let AI invent citations or quotes
  • Use causal words for survey data
  • List an AI tool as an author

05 · Your research ecosystem

Build your own AI research ecosystem

An ecosystem is the set of files, rules and tools that make every new study start where the last one ended, with your judgement at each gate.

You and EWURECResearch questions, ethics approval, final decisions, authorship
AgentsClaude Code, ChatGPT agent or Codex run multi-step pipelines with approval checkpoints
Tools and connectorsCode execution, Google Colab, connectors (MCP) to Drive, GitHub, Zotero
SkillsReusable procedures: survey-analysis-workflow, literature-screening, apa-reporting
Context filesresearch-context.md per study; CLAUDE.md or AGENTS.md in code folders
Projects and knowledgeOne Claude or ChatGPT Project per study with papers, codebooks, protocols
Data and recordsRaw data kept read-only, data management plan, prompt log, GitHub repository
Start smallOne Project and one context file this week; add a skill when you repeat a procedure for the third time.
Keep raw data read-onlyClean copies only; every change logged and reproducible from code.
Version everythingPrompts, context files, skills and code in a Git repository like this one.
Human checkpointsApprove plans before data change, and verify before results leave the chat.
Privacy by designIdentifiable data stays on approved systems; the AI sees anonymised or synthetic data.
Disclose and shareState AI use in every paper; share prompts and code so others can reproduce your work.
